# Smart Solution Website

Репозиторий сайта команды **Smart Solution**.

Сейчас проект находится на стадии постановки задачи. До начала реализации нужно согласовать цели сайта, аудиторию, контент, визуальные материалы и технические ограничения. Рабочие задачи ведутся в [GitHub Issues](https://github.com/michaelwelly/smart-solution-website/issues) и на [GitHub Project-доске](https://github.com/users/michaelwelly/projects/4).

## Базовый процесс

1. Уточнить и зафиксировать требования в брифе.
2. Согласовать структуру и прототип.
3. Выбрать стек и платформу размещения.
4. Реализовать MVP сайта.
5. Провести проверку на мобильных устройствах, настроить метаданные и публикацию.
